# Та ли Я — сайт массажного салона

Готовый одностраничный сайт с онлайн-записью. Без сборки, без зависимостей: открывается двойным кликом по `index.html`.

## 🔗 Публичная ссылка (для клиента)

**https://nikitaerin72-a11y.github.io/ta-li-ya/**

Хостинг — GitHub Pages, бесплатно и без ограничений по времени. Обновление: `git push` в ветку `main`, через минуту сайт пересобирается сам.


```
ta-li-ya/
├─ index.html        — страница
├─ css/styles.css    — стили
├─ js/app.js         — данные и логика записи
└─ README.md
```

## Как открыть

Двойной клик по `index.html`. Или локальный сервер (чтобы точно работало всё, включая localStorage):

```powershell
cd ta-li-ya
python -m http.server 8123
# открыть http://127.0.0.1:8123
```

## Что на сайте

- **Hero** с живым статусом «открыто/закрыто» и счётчиком свободных окон на сегодня
- **Услуги** — 3 категории (массаж / ногти / косметология), 17 позиций, табы
- **Онлайн-запись** в 4 шага: услуга → мастер → дата/время → контакты
  - календарь на 14 дней вперёд, шаг слотов 30 минут
  - занятые слоты исчезают автоматически (с учётом длительности услуги)
  - массаж и ногти не конфликтуют между собой — у них разные специалисты
  - валидация имени, телефона (маска +7 (999) 123-45-67) и согласия
  - экран «Готово»: кнопка **WhatsApp** с готовым текстом заявки и **кнопка «В календарь»** (.ics)
- **О салоне**, **отзывы** (реальные с Яндекс Карт), **контакты** с картой
- Мобильная версия со липкой кнопкой «Записаться», бургер-меню
- SEO: микроразметка LocalBusiness, meta/OG, семантика, доступность (skip-link, aria, focus-visible)

## Что поменять под себя

Всё в `js/app.js`:

| Что | Где |
|---|---|
| Телефон / WhatsApp | `PHONE`, `PHONE_PRETTY` (и ссылки `tel:` в `index.html`) |
| Рабочие часы | `WORK = { open: 10*60, close: 21*60, step: 30 }` |
| Услуги и цены | массив `SERVICES` (`price: null` → «по запросу») |
| Мастера | массив `MASTERS` |
| Текст отзывов | секция `#reviews` в `index.html` |

Цены на сайте — из карточки на Яндекс Картах. Для остальных услуг стоит «по запросу»: впиши свои.

## Про записи: важно

Сейчас заявка сохраняется **в браузере посетителя** (`localStorage`) и уходит в WhatsApp готовым сообщением. То есть салон получает заявку в мессенджере, а не в базе.

Чтобы заявки приходили на сервер, есть три простых варианта:

1. **Google Apps Script → Google Таблица** (бесплатно, 10 минут). Скрипт принимает POST и пишет строку. URL вставь в `ENDPOINT` в `js/app.js`.
2. **Telegram-бот** (нужен маленький прокси на VPS/Cloudflare Worker, чтобы не палить токен в браузере).
3. **Свой бэкенд** (PHP/Node) + админка со списком записей.

Пока `ENDPOINT = ''` — ничего не отправляется, всё работает локально.
